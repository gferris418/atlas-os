# Evidence and Verification

## Evidence states

- `CONFIRMED`
- `PROBABLE`
- `POSSIBLE`
- `DISPUTED`
- `UNVERIFIED`
- `STALE`

## Evidence rules

A source is distinct from a claim. Observation is distinct from inference. A URL is provenance, not proof by itself. Repetition does not create independent corroboration. Conflicts and uncertainty stay visible.

## Verification rule

Verification depth follows:

```text
risk × consequence × uncertainty × user requirement
```

Minimum completion checks are:

1. requested outcome met;
2. provider result reconciled;
3. material claims supported;
4. unresolved gaps exposed;
5. consequential actions have receipts.

ATLAS does not claim completion merely because a provider or subagent reports success.
