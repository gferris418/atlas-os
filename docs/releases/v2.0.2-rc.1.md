## Verification gate

Candidate packaging requires the dependency audit, unit, conformance, regression, integration, repository-validation, and deterministic-package checks. Passing those local gates does not close external host controls.

Stable `v2.0.2` promotion is blocked until:

- `MIG-029` captures independent fresh-session ChatGPT New Chat and ChatGPT Work bootstrap evidence; and
- `MIG-037`, after `MIG-029`, captures the same control revision on ChatGPT, Codex, Work, and Hermes Agent.

No checklist, repository-local test, or operator acceptance is a substitute for the required live evidence.

## Publication boundary

`v2.0.2-rc.1` may be tagged only on the exact validated candidate commit. The tag-triggered release workflow must verify tag/manifest identity and rebuild deterministic artifacts. Candidate publication does not imply stable release or completion of MIG-029 or MIG-037.
