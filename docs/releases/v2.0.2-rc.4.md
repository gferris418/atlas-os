# ATLAS-OS v2.0.2-rc.4

**Release channel:** Candidate  
**Control revision:** `atlas-bootstrap-2026-10-22-r8`  
**Target stable:** `v2.0.2`

## Summary

This candidate replaces universal taxonomy-first preflight with a triage-first architecture optimized for lower latency and clearer authority boundaries.

ATLAS now decides first whether a request is `GENERAL_SEARCH`, `GENERAL_TASK`, or `INTELLIGENCE`. Direct search/task work stays in ATLAS and resolves domain controls only when material. Intelligence-grade work delegates the canonical `intelligence_analysis` capability to the governed ARGUS specialist.

## Architecture

Four first-class machine contracts are now authoritative:

- `spec/mission-control.yaml` — human command and intervention;
- `spec/control-plane.yaml` — machine authority, permissions, routing, approvals, and state;
- `spec/observability.yaml` — metrics and read-only operational projection;
- `spec/domain-intelligence.yaml` — conditional domain semantics, standards, benchmarks, evidence hierarchy, and intelligence context.

`spec/request-triage.yaml` is the first semantic execution gate.

The Dashboard is explicitly separated from the Control Plane: displayed state is derived observability, not execution authority.

## Performance changes

- `GENERAL_SEARCH` and `GENERAL_TASK` no longer require full taxonomy/classification/framework work before execution.
- Domain context is evaluated only when it can materially affect correctness, authorization, safety, or outcome.
- Downstream provider logic cannot silently escalate a direct route into ARGUS activation.
- `INTELLIGENCE` can reach ARGUS with a governed `PARTIAL` handoff; ARGUS enriches unresolved intelligence context after activation.
- Government/public-sector/tender/company/person/topic mention alone does not activate ARGUS.

## ARGUS integration

ATLAS pins ARGUS Intelligence `2.1.0-rc.1` at commit `58459c2025f404598b13afe4567426b015c3e3eb` through `registries/domain-methods.yaml`.

The canonical specialist capability is `intelligence_analysis`. The previous `government_public_sector_opportunity_intelligence` capability remains temporarily available as a compatibility alias during this candidate line.

ARGUS supports strategic, market, opportunity, competitive, stakeholder, political-economic, monitoring, forecasting, scenario, and decision intelligence while remaining subordinate to ATLAS authority, permissions, planning, approvals, verification, persistence authorization, and final delivery.

## Verification

The ChatGPT, Codex, Work, and Hermes Agent machine verification contracts now test both fast-path cases:

1. plain tender lookup → `GENERAL_SEARCH`, no specialist;
2. opportunity assessment/ranking/monitoring → `INTELLIGENCE`, specialist `ARGUS`.
