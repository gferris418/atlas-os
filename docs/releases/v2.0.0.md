# ATLAS OS v2.0.0 Release Decision

**Date:** 2026-10-19  
**Channel:** stable  
**Status:** RELEASED  
**Predecessor:** 2.0.0-rc.12 at `45a8bf828abb1ab5242c54f798c5c074fd797285`

## Verification basis

ATLAS rc.12 passed dependency audit, unit, conformance, regression, integration, and repository validation before merge. The same merged rc.12 commit passed the complete `Validate ATLAS-OS` workflow on `main` in run `39276342409`, including deterministic snapshot generation.

The stable promotion changes release/version metadata, version-bound tests and adapters, changelog/release documentation, and migration release-blocking policy. It does not change the ATLAS runtime contracts used by ARGUS.

## Release-risk acceptance

The repository owner explicitly directed stable release without waiting for three external-only proofs:

- `MIG-029` — independent New Chat and ChatGPT Work bootstrap proof;
- `MIG-037` — independent latest-control propagation across supported surfaces;
- `DTIF-RECONCILIATION` — reconciliation requiring authoritative DTIF source data not present in the bootstrap repository.

These controls remain open or blocked, are recorded as post-GA work, and are not represented as passed or closed. Their `release_blocking` flag is false for v2.0.0 under this explicit operator decision.

## ARGUS compatibility

ARGUS rc.5 compatibility work was merged at `6f2136ff4f065dcab077fb58a0432c2a9d4c5389` against the immutable ATLAS rc.12 runtime/contract baseline. ARGUS stable promotion must repin to the exact ATLAS v2.0.0 merged commit while preserving the unchanged handoff, approval, runtime and verification contract hashes.

## Residual verification

External cross-surface bootstrap/propagation proof and the credentialed private-repository ATLAS↔ARGUS remote E2E remain post-release verification items. Their absence is explicitly disclosed and must not be converted into a successful verification claim without new evidence.
