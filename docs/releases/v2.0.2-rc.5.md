# ATLAS-OS v2.0.2-rc.5

**Release channel:** Candidate  
**Control revision:** `atlas-bootstrap-2026-10-22-r9`  
**Target stable:** `v2.0.2`

## Summary

This candidate makes the ATLAS/ARGUS boundary collection-first while preserving ATLAS as the fixed operating architecture.

- Mission Control, Control Plane, Domain Context Services, Data Plane, Assurance/Verification, Observability and Dashboard are explicit first-class ATLAS responsibilities.
- Task intent is separated from evidence collection mode.
- `collection_mode` is the authoritative ARGUS activation field: `NONE`, `ATLAS_DIRECT`, `ARGUS_COLLECTION`, `HYBRID`.
- ARGUS canonical capability becomes `intelligence_collection` and returns evidence packages; ATLAS retains strategic analysis, forecasting/scenarios, opportunity qualification, business decisions, assurance, persistence and delivery.
- `Domain Intelligence` is retired from active machine authority and retained only as a deprecated compatibility alias to Domain Context Services.
- Economic/domain classification is multi-axial and includes current governed references for ISIC Rev. 5, NACE Rev. 2.1, NAICS 2022, CPC 3.0, CPA 2.2, UNSPSC, CPV 2008, HS 2022 and NATO Codification when applicable.
- ARGUS 2.2.0-rc.1 is immutable and commit-pinned through the domain-method registry.
- Public-sector I0-I9 maturity and `PROMOTE_TO_PX` remain specialization semantics rather than universal ARGUS output.
