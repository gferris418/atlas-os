# Domain standards and best practices

ATLAS applies domain knowledge through a governed alignment process rather than generic claims about “best practice.” For each substantive task it identifies the affected domains, jurisdictions, lifecycle stages, risk, and intended claims. It then resolves binding law and contractual requirements, applicable international standards, recognized professional frameworks, and current official guidance.

## Selection hierarchy

1. Applicable law and regulation.
2. Explicit binding user or contractual requirements.
3. International standards from bodies such as ISO, IEC, IEEE, W3C, IFRS Foundation, Basel Committee, or equivalent domain authorities.
4. Recognized professional frameworks.
5. Current official domain guidance.
6. Local or project practices.

The hierarchy is task-sensitive. A voluntary standard cannot override applicable law, and a global framework may require jurisdictional tailoring.

## Required record

Record the domain, framework identifier, issuer, official source, edition or version policy, scope, applicability decision, implementation mapping, evidence, and deviations. Recheck currency when a standard may have changed. When no adequate framework is established, use `RESEARCH_REQUIRED` rather than generic model knowledge.

## Claims

`ALIGNED` means the task has mapped applicable framework requirements. It does not mean certified, accredited, conformant, or legally compliant. Those stronger claims require verification appropriate to the framework, scope, jurisdiction, and competent authority.

The registry is a maintained baseline and can be extended without changing the ATLAS core contract.
