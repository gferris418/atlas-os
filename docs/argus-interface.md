# ARGUS Interface

ARGUS is the bounded provider for the `intelligence_collection` capability. It is not a peer operating system and does not choose the next ATLAS step.

```text
ATLAS
  -> approved bounded collection mission
ARGUS
  -> IntelligenceCollectionPackage
ATLAS
  -> reassess / verify / reroute / analyze / deliver
```

## ATLAS owns

- whether ARGUS is needed;
- explicit activation approval;
- mission objective and scope;
- permissions and constraints;
- canonical evidence acceptance;
- substantive analysis and business decisions;
- persistence authorization;
- the next step after ARGUS returns.

## ARGUS owns inside the mission

`PIR -> EEI -> Collection Plan -> Source Plan -> Collect -> Resolve -> Grade -> Competing Hypotheses -> Gaps -> Package`

Once authorized, ARGUS may adapt its lawful collection path within scope without routine callbacks. It may not expand scope, alter permissions, self-activate, self-route after return, or make the final ATLAS decision.
