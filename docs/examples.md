# Examples

## Direct answer

**Request:** “Rewrite this supplier letter formally.”

Route: `NO_TOOL` → ATLAS produces the rewrite → verify format → deliver.

## Current tender lookup

**Request:** “Find the current Bangladesh Railway tenders.”

Route: `DIRECT_SEARCH` → host search provider → result returns to ATLAS → verify currency and relevance → deliver.

## Structured target intelligence

**Request:** “Build a dossier on ST Engineering for Bangladesh opportunities.”

Route: `ARGUS` → `AWAITING_APPROVAL` → explicit approval → bounded ARGUS mission → collection package returns to ATLAS → ATLAS evaluates evidence and decides analysis/next action.

## Hybrid decision support

**Request:** “Compare ST Engineering and L3Harris for Bangladesh opportunities.”

Route: `MULTI_CAPABILITY` → ATLAS may authorize ARGUS collection for each target → returns are reconciled → ATLAS performs the comparison and recommendation.

## External action

**Request:** “Send this proposal to the client.”

Route: `EXTERNAL_ACTION` → approval check → authorized host action → receipt returns to ATLAS → ATLAS verifies execution before reporting success.
