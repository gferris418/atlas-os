# Security policy

Report suspected security issues privately to the repository owner. Do not include credentials, personal data, exploit details, or private system output in public issues.

ATLAS treats permission changes, credential handling, external publication, destructive actions, and security-sensitive modifications as approval-gated operations. Validation and test fixtures must not contain secrets.

Operators managing ATLAS control-record signing keys must follow the
[signing-key management runbook](docs/key-management.md), including custody,
rotation, revocation, registry distribution, and read-back verification.
